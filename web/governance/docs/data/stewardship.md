# Responsabilidades

| Rol | Decide sobre |
|---|---|
| Responsable de reportes (MIS) | alcance, fechas, SQL y reglas de cada reporte |
| Producción (carga de tablas) | actualizar tablas al corte cuando se solicita ([proceso](../development/runbooks/solicitud-actualizacion-tablas.md)) |
| Administrador de BD | accesos, usuarios de lectura/escritura, linked servers, corrección de duplicados |
| Solicitantes (Riesgos, Finanzas, Gerencia) | definición de negocio de cada cifra |
| Seguridad | rotación de credenciales y revisión de permisos |

Los solicitantes y destinatarios por reporte están en el [catálogo de reportes](../business/domain-catalog.md).
